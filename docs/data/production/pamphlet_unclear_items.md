## AI回答方針

- 不明項目は「資料では確認できません」と答える。
- 不明項目を「たぶん」「おそらく」で補完しない。
- 料金、場所、アレルギー、販売物、所要時間、人数制限は、資料にあるものだけ答える。
- 当日変わりうる情報は、スタッフ確認または当日案内へ誘導する。

## 全体の注意

- 企画ごとの正確な所要時間はパンフレットからは読み取れないため、10〜25分程度の仮値を設定しています。
- 待ち時間の初期値はすべて `0` にしています。当日はスタッフ画面またはadmin画面で更新してください。
- マップ用の `location_x` / `location_y` はパンフレット配置を参考にした仮座標です。正確な校内地図座標ではありません。
- 整理券の有無は多くの企画で読み取れないため、料金情報をもとに `有料` / `無料` を `ticket_status` に入れています。
