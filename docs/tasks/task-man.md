# 白龍 AIガイドシステム - 人間担当タスクリスト (運営・管理者向け)

このリストは、AIでは実行不可能な「実データの収集」「環境の物理的なセットアップ」「関係者との調整」など、人間が主体となって行うべきタスクをまとめたものです。

## 1. データの収集と整理（最優先）
AIが回答を生成するための「正確なソース」を準備してください。
- [ ] **展示情報のリスト化**: 
    - 展示名、場所（教室名）、紹介文、体験時間、飲食物の有無などをExcelやMarkdownでまとめてください。
- [ ] **学内マップの距離データ作成**: 
    - 「A教室からB教室まで歩いて何秒かかるか」というデータを主要なポイント間で計測し、メモしてください。これが行程最適化の精度に直結します。
- [ ] **シフトスケジュールの収集**: 
    - 運営に協力してくれる生徒のシフト時間をデータ化し、AIに読み込める形式にしてください。

## 2. 環境構築とハードウェア準備
AIが動作するための物理的な土台を作ってください。
- [ ] **Ollamaのインストール**: 
    - 使用するPC（Ryzen AI MAX搭載機など）に [Ollama](https://ollama.com/) をインストールし、`llama3.1` などのモデルが `ollama run` で動くことを確認してください。
- [ ] **ネットワーク環境の整備**: 
    - 白龍祭当日に来場者がサーバーにアクセスできるよう、学内Wi-Fiの許可を取るか、専用のWi-Fiルーター（ローカルネットワーク用）を設置してください。
- [ ] **ハードウェアの確保**: 
    - サーバーとして常時稼働させるPCと、モニタリング用のディスプレイを確保し、設置場所を決定してください。

## 3. 調整と運用ルール
システムを円滑に動かすための「人間同士の約束事」を決めてください。
- [ ] **スタッフへの説明と協力要請**: 
    - 各展示の担当者に、待ち時間を更新してもらうための手順を説明してください。
- [ ] **スタッフ用ログインPINの決定**: 
    - 展示スタッフが更新画面に入るための簡単なPINコード（4桁など）を決め、周知してください。
- [ ] **白龍の「キャラ設定」の最終決定**: 
    - AIの口調（敬語か、親しみやすいか、特定の語尾があるかなど）を決定してください。

## 4. 現場でのテストと検証
実装されたシステムが現場で使い物になるか確認してください。
- [ ] **スマホ実機での接続テスト**: 
    - 実際に自分のスマホからサーバーのURLにアクセスし、画面が正しく表示されるか確認してください。
- [ ] **待ち時間更新テスト**: 
    - スタッフ画面から待ち時間を変えたとき、ユーザー画面が即座に変わるか、実際の展示場所からテストしてください。
- [ ] **回答精度の最終チェック**: 
    - 展示内容についてAIに質問し、間違った回答（ハルシネーション）がないか、重要な情報が抜けていないかを確認してください。

## 5. 当日の運用
- [ ] **サーバーの常時監視**: 
    - PCがスリープしたり、プログラムが停止したりしていないか、定期的に確認してください。
- [ ] **バックアップデータの準備**: 
    - ネットワークトラブルに備え、展示一覧の掲示板（アナログ）も用意しておくことを推奨します。
