# 白龍 AIガイドシステム - 詳細タスクリスト

このドキュメントは、白龍祭（文化祭）向けAIガイドシステム「白龍」を構築するための全工程を網羅した詳細なタスクリストです。

## 1. プロジェクト基盤・環境構築
- [ ] バックエンド用プロジェクト構造の初期化 (FastAPI)
- [ ] フロントエンド用プロジェクト構造の初期化 (React + TypeScript + Vite)
- [ ] ハードウェア最適化の設定 (Ryzen AI MAX向けの環境構築)
- [ ] Ollamaのセットアップと特定モデル (Llama 3.1 / Gemma 2) のロード・検証
- [ ] Docker等のコンテナ化（ローカル環境のポータビリティ確保、任意）
- [ ] 共通のデザインガイドライン（カラーパレット、フォント、アイコン）の定義

## 2. データ準備 & RAGシステム (AIレイヤー)
- [ ] 展示情報データの収集と構造化 (JSON/Markdown形式)
    - [ ] 展示名、場所（教室番号）、内容詳細、開催時間
    - [ ] 展示の種類（飲食、体験、展示など）のタグ付け
- [ ] RAG用ドキュメント分割（Chunking）戦略の策定
- [ ] 埋め込み（Embedding）モデルの選定とベクトルDB (ChromaDB/FAISS) の初期化
- [ ] 検索（Retrieval）ロジックの実装
    - [ ] 類似度検索の精度調整
    - [ ] 関連情報のフィルタリング機能
- [ ] プロンプトエンジニアリング
    - [ ] 語尾やトーン（「白龍」らしいキャラクター付け）の設定
    - [ ] 未知の質問に対する「分かりません」回答の徹底

## 3. バックエンド開発 (FastAPI)
- [ ] API設計とドキュメント作成 (Swagger UI)
- [ ] データベース（SQLite）のスキーマ定義

    - [ ] `wait_times` テーブル (動的な待ち時間)
    - [ ] `staff_accounts` テーブル (認証用)

- [ ] 待ち時間管理エンドポイントの実装

    - [ ] 取得用 (`GET /wait-times`)
- [ ] スタッフ認証ロジック (PINコードまたはJWT) の実装
- [ ] 行程プランニングAPIの実装
