# 実装レポート 1：システム基盤の構築 (report-ai-1.md)

## 1. 現在の状況
「白龍 AIガイドシステム」の土台となるシステム基盤の実装が完了しました。具体的には以下のコンポーネントが準備されています。

- **バックエンド (FastAPI)**: サーバーの本体。データのやり取りやAIとの接続を管理します。
- **フロントエンド (React + Vite)**: ユーザーが見る画面の基礎。
- **データベース (SQLite)**: 展示情報や待ち時間を保存するための保管庫。
- **AI接続クライアント (Ollama Client)**: ローカルで動くAI（Ollama）と通信するための機能。
- **統合起動スクリプト (run.py)**: 全てを一括で起動するための便利なボタンのような役割をします。

## 2. 現在の状況でできること
ITに詳しくない方でも、以下のことが確認可能です。

- **サーバーの起動**: ルートディレクトリにある `run.py` を実行すると、バックエンドとフロントエンドが同時に立ち上がります。
- **管理画面の確認**: ブラウザで `http://localhost:8000/docs` を開くと、バックエンドが正しく動いているか、どのような命令（API）が準備されているかを一覧で見ることができます。
- **フロントエンドの表示**: ブラウザで `http://localhost:5173` を開くと、Viteの初期画面が表示され、画面開発の準備ができていることがわかります。

## 3. 人間が知っておくべきこと
- **PythonとNode.js**: このシステムを動かすには、コンピュータに Python と Node.js がインストールされている必要があります。
- **仮想環境 (venv)**: バックエンドは `backend/venv` という隔離された環境で動いています。
- **データベース**: `backend/sql_app.db` というファイルにデータが保存されます。

## 4. 現段階で絶対すべきこと
- **Ollamaのインストールと起動**: AIの回答機能を使うためには、PCに [Ollama](https://ollama.com/) をインストールし、起動しておく必要があります。
- **モデルのダウンロード**: デフォルトでは `llama3` というモデルを使用するように設定しています。ターミナルで `ollama run llama3` を実行して、モデルを事前にダウンロードしておいてください。
- **フロントエンドのライブラリインストール**: 初回起動時には `frontend` ディレクトリで `npm install` を実行する必要があります（`run.py` が自動で行うようになっていますが、ネットワーク環境によっては時間がかかる場合があります）。
