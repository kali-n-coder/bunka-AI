# 白龍AIガイドの使い方

白龍AIガイドは、白龍祭の企画、場所、待ち時間、ステージ予定などを調べられる案内システムです。  
会場内に設置されたPCや、案内されている待ち時間ページから利用できます。

## できること

- 企画の名前や内容を調べる
- 企画の場所を確認する
- 現在の待ち時間を見る
- 飲食企画やアレルギー情報を確認する
- ステージ予定を確認する
- どこに行くか迷ったときに相談する

## 使い方

### 設置PCを使う場合

1. 画面を見て、調べたい内容を選びます。
2. チャット欄がある場合は、聞きたいことを短く入力します。
3. 回答に出てきた場所や注意事項を確認します。
4. 分からないことが残ったら、近くのスタッフに声をかけてください。

質問例:

```text
オカダナルドはどこ？
飲食企画を教えて
待ち時間が短い企画は？
今日の外ステージ予定を教えて
スタンプラリーはどこから始まる？
```

### 待ち時間ページを使う場合

掲示されているQRコードを読み取ると、スマホから待ち時間一覧を確認できます。  
待ち時間は目安です。実際の列の状況とはずれる場合があります。

## 注意

- AIの回答は、パンフレットや登録済み資料をもとにした案内です。
- 資料にないことは「資料では確認できません」と表示される場合があります。
- 最新の変更、売り切れ、雨天時変更、混雑時の入場制限は、近くのスタッフや当日案内を確認してください。
- 緊急時はAIではなく、先生・白龍祭スタッフの指示に従ってください。
- 個人情報、生徒名、連絡先、写真やSNS投稿に関する判断は、スタッフに確認してください。

## 困ったとき

次のようなときは、近くの白龍祭スタッフに声をかけてください。

- 画面が動かない
- 答えがよく分からない
- 場所が分からない
- 迷子、落とし物、体調不良がある
- AIの回答と現地の案内が違う

白龍AIガイドは案内を手伝うためのものです。  
最終的な案内は、当日のスタッフ・先生の指示を優先してください。
